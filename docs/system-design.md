# 선거분석 Project 01 설계서

## 처리 흐름

공식 결과 파일과 출처 정보를 등록한다. Python으로 지역 코드와 수치 형식을 정리한 뒤 필수값, 중복, 집계 합계를 검사한다. 검증에 통과한 집계만 조회용으로 내보내고 화면의 표와 그래프는 같은 집계 결과를 사용한다. 저장 기술과 화면 프레임워크는 원자료 확인 후 결정한다.

## 데이터 구조

| 데이터 | 기본키(PK) | 외래키(FK) 및 주요 값 |
| --- | --- | --- |
| 선거 | election_id | 선거명, 종류, 선거일 |
| 지역 | region_id | 공식 지역 코드, 지역명, 집계 수준, 적용 기준일 |
| 출처 | source_id | 원문 URL, 기준일, 수집 시각, 이용 조건, 원본 식별값 |
| 후보 | candidate_id | election_id → 선거, 후보명, 공식 후보 식별값 |
| 지역 투표 집계 | election_id + region_id | 선거·지역·출처 참조, 선거인 수, 투표자 수, 유효투표수, 무효투표수 |
| 후보 득표 집계 | election_id + region_id + candidate_id | 지역 투표 집계와 후보·출처 참조, 득표수 |

선거 ID는 한 종류의 투표를 구분할 수 있는 단위로 부여한다. 한 선거에서 선거구별 후보 명단이 다르면 선거구 식별값도 관리해 해당 집계에 속한 후보만 연결한다.

## 화면 구성

| 영역 | 표시 항목 | 동작 |
| --- | --- | --- |
| 검색 조건 | 선거, 지역, 비교 기준 | 선택 변경 시 조회 결과를 갱신 |
| 지역 비교 | 투표율 막대그래프와 집계표 | 선택한 집계 수준의 지역을 같은 기준으로 비교 |
| 후보 결과 | 후보별 득표수와 득표율 | 선택 지역의 결과를 조회 |
| 자료 정보 | 원문 링크, 집계 기준일, 지표 정의 | 원자료 열기와 계산 기준 확인 |

## 검증과 갱신
- 동일 파일은 원본 식별값으로 확인한다. 동일 집계 키가 한 파일에서 반복되면 중복 사유를 확인한다.
- 비교 가능한 동일 집계 범위에서 후보 득표 합계와 유효투표수, 유효·무효표 합계와 투표자 수를 대조한다.
- 원자료 정정본은 별도 버전으로 제출하고 검증 완료 후 조회본을 갱신한다. 이전 자료와 오류 기록을 보존한다.
- 조회 결과의 표와 그래프 수치를 대조하고, 결측값·0표·빈 검색 결과를 각각 확인한다.
