# 선거분석 Project 01 기획서

## 목적
공식 선거 결과를 지역별로 비교해 일반 독자가 투표율과 득표율의 차이를 이해하도록 돕는다. 기자와 편집자는 화면의 수치를 원자료까지 추적할 수 있어야 한다.

## 초기 범위
- 첫 분석은 같은 선거의 동일한 집계 단위에서 지역을 비교한다.
- 대상 선거와 대상 지역은 원자료의 범위와 완결성을 확인한 뒤 확정한다. 지역 이름은 공식 코드와 함께 관리한다.
- 중앙선거관리위원회 선거통계시스템을 우선 자료 후보로 둔다. 사용 파일, 원문 URL, 집계 기준일, 이용 조건은 수집 시 확인해 기록한다.
- 선거 간 비교는 선거 종류, 지역 경계 및 집계 기준이 일치할 때 후속 범위로 다룬다.

## 독자 경험
독자가 선거와 지역을 선택하면 투표율과 후보별 득표율을 표와 그래프로 볼 수 있다. 각 지표의 분모와 자료 기준을 함께 표시한다. 기사 작성자는 표에서 수치를 확인하고 원문으로 이동해 대조한다.

## 작업 순서와 완료 기준

| 단계 | 산출물 | 완료 기준 |
| --- | --- | --- |
| 자료 확인 | 원자료 목록, 지표 정의 | 출처, 이용 조건, 집계 단위와 지표 분모를 확인 |
| 전처리 | 정제 데이터, 오류 기록 | 중복·누락·합계 불일치를 확인하고 재현 가능하게 기록 |
| 구현 | 비교 화면, 집계표 | 같은 선택 조건에서 표와 그래프 수치가 일치 |
| 편집 검수 | 검수 기록 | 수치·출처·분모를 원문과 대조하고 표현 점검 |

## 편집 원칙
지역별 차이는 관측된 결과로 설명한다. 투표 동기나 개인의 선택은 집계값만으로 판단할 수 없다. 개인정보가 포함된 행 단위 자료는 공개 저장소에 올리지 않는다.
