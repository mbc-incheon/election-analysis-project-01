# 선거분석 Project 01 기능정의서

아래 항목은 초기 구현 목표다.

| ID | 기능 | 사용자 동작 또는 처리 | 완료 기준 |
| --- | --- | --- | --- |
| F-01 | 자료 등록 | 작업자가 공식 결과 파일과 출처 정보를 등록한다. | 원문 링크, 수집 시각, 기준일, 집계 단위를 함께 조회할 수 있다. |
| F-02 | 데이터 검증 | 시스템이 필수값, 중복, 음수, 합계를 검사한다. | 문제가 있는 행과 사유를 기록한다. 검증 실패 자료는 공개 조회에 반영되지 않는다. |
| F-03 | 선거·지역 조회 | 독자가 선거와 같은 집계 수준의 지역을 선택한다. | 선택한 조건을 표시한다. 자료가 없으면 빈 결과 안내를 표시한다. |
| F-04 | 투표율 비교 | 독자가 지역별 투표율을 표와 막대그래프로 본다. | 투표자 수, 선거인 수, 투표율이 표시되고 표와 그래프의 값이 일치한다. |
| F-05 | 후보 득표율 조회 | 독자가 지역을 선택해 후보별 득표 결과를 본다. | 후보 이름, 득표수, 유효투표수 기준 득표율이 표시된다. |
| F-06 | 출처 확인 | 독자가 결과의 자료 기준과 원문을 확인한다. | 원문 링크, 집계 기준일, 지표 분모를 확인할 수 있다. |

## 지표 계산

| 지표 | 계산식 | 표시 |
| --- | --- | --- |
| 투표율 | 투표자 수 ÷ 선거인 수 × 100 | % |
| 후보 득표율 | 후보 득표수 ÷ 해당 선거·지역의 유효투표수 × 100 | % |
| 투표율 차이 | 비교 지역 투표율 − 기준 지역 투표율 | %p |

분모가 0이거나 필요한 값이 없으면 ‘계산 불가’를 표시한다. 원자료에 명시된 0표는 0으로 보존한다. 계산에는 원자료의 정수 값을 사용하고, 반올림은 표시 단계에서 적용한다. 비교 기준 지역은 결과에 함께 표시한다.
